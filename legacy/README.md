# The original hackathon code (unchanged)

These are the original files from the Phi-2 hackathon (February 2024), by Michael Lively and team "The Phi Generation". They are kept here, unchanged, for one reason: the tests in `tests/test_legacy_bugs.py` run against them to prove the bugs this fork fixes.

The app no longer uses these files. The whole original repo is also saved in the git tag `original-hackathon`.

| File | What it was |
|---|---|
| `app.py` | The Streamlit app |
| `crewai/` | A 2024 copy of the CrewAI library, with two added tools: `tools/phi2_tools.py` and `tools/gemini_tools.py` |
| `requirements.txt` | The original libraries |
